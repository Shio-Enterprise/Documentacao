# Divisão do Grupo

## Organização da Equipe <!-- {docsify-ignore} -->

O grupo foi organizado utilizando uma metodologia baseada em **Squads**, com o objetivo de distribuir melhor as atividades, permitir a execução paralela das tarefas e facilitar a colaboração entre os integrantes.

A equipe foi dividida em quatro squads, cada uma composta por um conjunto de membros responsáveis por executar e acompanhar as tarefas atribuídas ao seu grupo.

## Metodologia de Trabalho <!-- {docsify-ignore} -->

A divisão em squads foi utilizada como estratégia para organizar o desenvolvimento do projeto e distribuir as demandas entre os integrantes.

Cada squad recebeu um conjunto de tarefas ou responsabilidades relacionadas ao projeto. Dentro de cada squad, os integrantes puderam dividir as tarefas entre si de acordo com a necessidade de cada demanda.
